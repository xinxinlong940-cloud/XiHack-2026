# 《大唐西市》历史证据文档

> 文档性质：历史边界与影像表现审查表。它说明哪些内容可以作为史实背景（H）、哪些只能作为有史实基础的推演（I）、哪些必须明确为原创（F）。它不是剧情母文档，也不为具体剧情数值提供“历史背书”。
>
> 时代口径：盛唐、唐玄宗时期、8 世纪前半叶。现阶段不锁定未经研究确认的精确年份。

## 1. 判定与引用规则

- **H（Historical Fact）**：有传世制度文献、同时代文书、铭刻/器物或正式考古材料支撑。H 只覆盖来源实际能证明的最小命题。
- **I（Historically Inspired）**：从 H 出发的合理复原，例如具体查验动作、市场日常对话、无名商人的经营方式。I 不能用“当时一定如此”表述。
- **F（Fiction）**：原创人物、事件、对白、选择、结果、结局及游戏状态数值。F 不得反向用历史资料包装成真实个案。
- **后世文献**：宋、清等后世材料可以帮助复原，但必须注明成书时代，不单独当作唐代直接证据。
- **待核实**：表示目前尚未完成版本、卷次、页码、文物编号或原始报告的交叉核验；在核验完成前，不得把相应细节写成确定史实。

### 证据类型说明

| 类型 | 含义 | 使用优先级 |
|---|---|---|
| 唐代制度文献/同时代文书 | 唐代形成的律令、官制文本或实际交易、通行文书 | 高；仍需核对具体版本与条文语境 |
| 考古遗址/出土器物/墓志 | 可定位的遗址、器物、铭刻、墓志与正式发掘材料 | 高；只证明材料本身，不自动证明剧情行为 |
| 后世文献 | 宋以后编纂、追记唐代情况的文献 | 中；必须注明时代与材料局限 |
| 现代研究 | 基于史料或考古材料的学术专著、论文 | 中；优先使用可追溯原始材料者 |
| 剧情设定 | 本项目原创设定 | 不属于历史证据，只用于划定 F |

## 6. 来源质量结论

- **证据较强，可支撑最小 H 命题**：唐长安西市及市署制度、过所制度、《唐律疏议》对过所违法行为的规范、唐代契约环境、粟特人在华与物质文化交流的总体背景。
