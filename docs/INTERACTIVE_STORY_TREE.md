# 《大唐西市》互动剧情母文档

> 权威性：本文件是后续剧情、分镜与视频节点制作的唯一权威来源。其他角色文档只摘录各自线路；如有冲突，以本文件为准。

## 1. 叙事边界与结构

- 项目定位：AIGC 历史互动短剧 / 互动视频。视频是作品本体，互动网页是观看方式。
- 核心表达：**同一座西市，三种身份，三条人生。**
- 时代背景：盛唐、唐玄宗时期、8 世纪前半叶；在研究确认前不指定精确年份。
- 标注：`H` = 有可靠证据支持的历史事实；`I` = 基于历史环境的合理推演；`F` = 原创人物、事件、对白、选择、数值与结局。
- 素材：**公共素材**供同一节点各路径复用；**分支素材**只表现一次选择的短结果。分支结果后尽量汇合。
- 当前制作结构：`P01 → K01—K04 / J01—J04 → S01—S04 → END01—END03`。观众选择康延或阿九后，完成当前人物线即可进入三人会合；阿郎个人线因制作时间暂停，不提供入口。
- 状态效果均为增减量；结算后仍须遵守 `data/interactive/state_schema.json` 的边界，例如 `ajiu.nameValue` 保持在 `0—3`，不得因负向选择产生越界值。阿郎的 `informationValue` 保留作历史草案兼容字段，当前剧情不累积、不展示，也不参与结局判断。

三个主角均为原创人物（F）：康延是粟特背景的胡商学徒，阿九是西市年轻匠人，阿郎是西市交易撮合者。阿郎不具有官方裁判权，也不写成“官方牙郎”。

## 2. 序章

### P01｜西市开市与角色选择

- 人物目标：让观众理解西市中卖货与制货的两种生存位置，并选择本轮跟随谁。
- 现实冲突：同一商业空间中，不同身份承担不同风险。
- 节点 H/I/F：历史空间与商业活动为 H/I；具体人物、调度、旁白和选择为 F。

| 幕 | 画面 | H/I/F | 素材 |
|---|---|---|---|
| P01-M01 | 西市清晨大全景；商铺开门，商贩、行人、商旅逐渐进入市场。 | H/I | 公共素材 |
| P01-M02 | 商业空间组接：绢行、普通店铺、货摊与往来商旅。 | H/I | 公共素材 |
| P01-M03 | 年轻匠人工作，建立阿九这一类人物的视觉氛围。 | I/F | 公共素材 |
| P01-M04 | 康延查看货物与钱袋，阿九整理刚完成的器物。 | F | 公共素材 |
| P01-M05 | 康延、阿九分别出现在西市不同位置，随后出现本轮人物视角选择。阿郎不在序章出现。 | F | 公共素材 |

旁白核心意思（F）：“有人来这里卖货，有人来这里做货。同一座西市，各有各的难处。”

| 选择 | 效果 | 可见后果 | 下一节点 |
|---|---|---|---|
| A｜选择康延 | 不改变数值；设置 `storyFlags.viewpoint = kangyan` | 镜头跟随康延 | K01 |
| B｜选择阿九 | 不改变数值；设置 `storyFlags.viewpoint = ajiu` | 镜头跟随阿九 | J01 |

完成所选线路后直接进入 S01。每次开始人物线时重置本轮数值；已体验标记保留，但不把不同轮次的数值累计或用于刷取门槛。
